# Screenshots

Add your screenshots to the correct day folder.

## Folder Structure

```
screenshots/
├── day1/     ← VNet creation, peering connected status
├── day2/     ← NSG rules, VM overview, webpage on mobile
├── day3/     ← Bastion deployment, VM access without public IP
├── day4/     ← Route tables, UDR configuration
├── day5/     ← Azure Firewall rules, spoke-to-spoke test
├── day6/     ← Application Gateway, backend health
├── day7/     ← DNS zones, Traffic Manager
└── day8/     ← Monitor dashboards, Network Watcher results
```

## Naming Convention

Use descriptive names so screenshots are self-explanatory:

| Example Filename | What to Capture |
|---|---|
| `day1-hub-vnet-created.png` | Hub VNet overview page |
| `day1-peering-connected.png` | Peering status showing Connected |
| `day2-nsg-rules.png` | NSG inbound rules list |
| `day2-webpage-working.png` | Browser showing the blue webpage |
| `day3-bastion-deployed.png` | Bastion resource overview |
